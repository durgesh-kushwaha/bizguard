# BizGuard — Project Overview

## What is BizGuard?

BizGuard is a **Business Decision Intelligence System** that combines Big Data Analytics and Machine Learning to help businesses make informed decisions.

### Core Concept
> "Test the decision before you make it."

BizGuard allows a business user to:
1. Upload business transaction data
2. Analyze performance using big data analytics
3. Predict future demand using machine learning
4. Simulate business decisions (pricing, inventory, marketing)
5. Evaluate scenarios with risk and assumption transparency
6. Track decisions for future comparison

## The Four Questions

| Question | How BizGuard Answers It |
|----------|------------------------|
| What happened? | BDA analytics and KPIs |
| What is likely to happen? | ML demand prediction |
| What if I change something? | Decision simulation |
| What should I watch? | Monitoring triggers |

## Academic Context

- **BDA** (Big Data Analytics): PySpark processing, aggregations, analytics
- **IML** (Introduction to Machine Learning): Supervised learning, model training, evaluation

## Technology Stack

- Python 3.9+
- Streamlit (UI)
- Pandas/NumPy (Data processing)
- PySpark (Big Data processing)
- scikit-learn (Machine Learning)
- Plotly (Visualization)
- SQLite (Decision persistence)
